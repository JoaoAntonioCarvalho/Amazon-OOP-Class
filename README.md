# Product Manager (C# / Windows Forms)

A Windows Forms desktop app built for an Object-Oriented Programming class. It manages a simple product catalog inspired by an online store.

## Tech

C# · .NET · Windows Forms

## Features

- Add products with ID, name, description, category, and size
- Remove a selected product or clear the whole list
- Count the products in the catalog
- Input validation: the `Product` class rejects empty names through property setters

## OOP concepts practiced

- Classes and objects (`Product`)
- Constructor overloading
- Encapsulation with properties and validation in setters
- Event-driven UI (button click handlers)
